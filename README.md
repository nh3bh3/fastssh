# 增强版文件传输工具 v2.0

在两台 Windows 电脑间快速传输大量文件/文件夹的多协议便携工具。

## 🚀 新功能特性

### 多协议支持
- **TCP Socket** - 点对点高速传输（推荐）
- **FTP** - 传统FTP协议传输
- **HTTP/HTTPS** - Web服务器传输
- **SMB** - Windows网络共享传输

### 增强功能
- 📊 **实时进度显示** - 传输进度条和速度监控
- 🔄 **自动重试机制** - 传输失败自动重试
- ✅ **文件校验** - MD5完整性校验
- 📝 **详细日志** - 完整的传输日志记录
- 🎯 **文件过滤** - 支持通配符文件筛选
- 📁 **批量传输** - 支持多文件批量传输
- 🗜️ **智能压缩** - 三级压缩选择（快速/标准/最佳）
- ⏯️ **传输控制** - 暂停/停止/继续传输

## 使用方法

### 快速开始
1. 双击运行 `启动传输工具.bat` 或直接运行 `fast_transfer.exe`
2. 选择传输协议和模式
3. 配置发送/接收参数，点击"开始传输"

### 详细步骤

#### 发送端设置
1. 选择"发送文件"模式
2. 选择传输协议（TCP推荐）
3. 点击"..."选择要发送的文件或文件夹
4. 设置监听端口（默认9000）
5. 选择压缩级别
6. 点击"开始传输"

#### 接收端设置
1. 选择"接收文件"模式
2. 选择相同传输协议
3. 填写发送端IP地址
4. 设置端口号（与发送端一致）
5. 选择保存位置
6. 点击"开始传输"

## 协议说明

### TCP Socket（推荐）
- **优点**: 最快，点对点，无需服务器
- **适用**: 局域网传输
- **端口**: 默认9000

### FTP传输
- **优点**: 兼容性好，支持断点续传
- **适用**: 需要FTP服务器的环境
- **注意**: 需要有效的FTP服务器

### HTTP/HTTPS传输
- **优点**: 通用性强，支持加密
- **适用**: 通过Web服务器传输
- **注意**: 需要支持上传的Web服务器

### SMB传输
- **优点**: Windows原生支持
- **适用**: Windows网络共享
- **注意**: 需要网络共享权限

## 高级功能

### 文件过滤
支持通配符过滤：
- `*.txt` - 只传输TXT文件
- `*.jpg;*.png` - 传输图片文件
- `-*.tmp` - 排除临时文件

### 传输日志
- 实时记录传输状态
- 错误信息详细记录
- 支持日志导出和清除

### 批量传输
- 支持同时传输多个文件
- 文件队列管理
- 传输状态跟踪

## 注意事项

- **网络要求**: 确保双方在同一网络或可相互访问
- **防火墙**: 确保传输端口未被防火墙阻止
- **权限**: SMB传输需要适当的网络共享权限
- **临时文件**: TCP传输会在%TEMP%目录创建临时压缩文件
- **文件覆盖**: 接收时会覆盖同名文件，请谨慎操作
